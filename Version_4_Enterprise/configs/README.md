# Configs

Configuration command scripts used in the build.

| File | What it configures |
|---|---|
| `etherchannel-jb.txt` | LACP EtherChannel between Server_Switch and JB_Multilayer_Switch |
| `layer2-security-kl-mgmt.txt` | Port security and DHCP snooping on KL_Management_Switch |

Full `show running-config` dumps of the core devices (CoreA, CoreB, routers) are still to be added. Credentials are never stored in this repository.
